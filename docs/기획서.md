# 한 번뿐인 인생 — 게임 기획서

Oct 21, 2026 · @white0x

## 한 줄 소개

**서울에서 고등학교 1학년으로 시작해 죽을 때까지, 인생 한 번을 사는 도트 인생 시뮬레이션.** 다시 하기는 없다.

- 북극성: **극한의 현실감 + 극한의 자유도 = 완전히 살아 숨 쉬는 세계**
- 주인공: 남자 고등학생 (고정). 인생 경로는 공부·일·장사·운동·창작·범죄까지 열려 있다
- 느낌: 스타듀밸리·위치브룩처럼 직접 몸을 움직여 사는 게임, 배경은 지금의 서울 동네
- 저장소: [github.com/ooohi000/one-life](https://github.com/ooohi000/one-life) (작업 브랜치 `feature/mvp`)

## 핵심 원칙

모든 설계·구현 판단은 이 여섯 가지로 한다.

1. **행동에는 대가가 따르고, 그 대가는 늦게라도 돌아온다.** 학폭은 몇 달 뒤 신고로, 땡땡이는 성적과 부모 신뢰로 돌아온다.
2. **콘텐츠가 아니라 서로 반응하는 규칙으로 자유도를 만든다.** 대본 없이 상황에 따라 대사와 사건이 생긴다.
3. **모든 NPC는 자기 스탯·취향·기억·의지·인생 목표를 가진다.** 주인공이 없어도 세계는 굴러간다.
4. **인생 루트에 정답은 없다.** 공부가 늘 좋은 길이 아니다. 길마다 열리는 문이 다를 뿐이고(학벌·기술·장사·몸·인맥), 평가는 그 사람이 원했던 것 기준이다.
5. **풍자 대상은 사람이 아니라 구조다.** 국적·성별 집단에 성격을 박지 않는다.
6. **숨겨진 수치는 숫자가 아니라 증상·외형·사건으로 드러낸다.** 살찌면 몸이 보이고, 맞으면 멍이 보인다.

## 게임 구조

하루는 갈림길의 연속이고, 그 갈림길마다 주인공은 플레이어가, NPC는 AI가 고른다. 같은 흐름을 모두가 탄다.

**인생 흐름** (지금은 고1만)

- 고등학교 1\~3학년 → 졸업 후 갈래(대학·취업·창업·운동·군대) → 20대 → 중년 → 노년 → 죽음
- 연애·결혼·집(월세·전세·매매·청약)·직업·사업은 성인 단계에서 열린다

**하루 흐름** (지금 화면)

1. 아침: 날씨·동네 소식·그동안 있었던 일, 우산 챙길지 고르기
2. 학교 (아직 장면 없음 — 엔진에서는 돌아감)
3. 동네를 걸어 알바 가기 — 집·치킨집으로 새면 무단결근
4. 편의점 근무: 직접 계산·진열·청소, 양심 선택
5. 정산 → 다음 알바 날까지 며칠은 평소의 나처럼 흘러감

**직접 하는 노동**: 일은 카드로 고르지 않는다. 스타듀처럼 직업마다 자기 화면·손놀림이 있고, 처음엔 손으로 하다가 성공하면 관리자가 된다.

**저장**: 시드 + 주인공의 선택 목록. 불러오기 = 같은 시드로 세계를 만들고 선택을 다시 넣기 (같은 세계가 다시 나온다).

## 콘텐츠 기준

현실의 어두운 면도 넣되, 보여 주는 방식에는 선이 있다.

- **폭력·범죄는 결과로 보여 준다.** 방법은 자세히 그리지 않는다 (싸움 후 멍·신고·처분).
- **힘든 가정은 있다.** 학대·방임 부모는 NPC에게 현실 비율대로, 주인공은 ‘힘든 가정에서 시작하기’를 골랐을 때만. 가정폭력 끄기 설정을 둔다.
- **성적 내용은 성인 캐릭터끼리, 암시·암전 수준까지만.** 강요로 설득하는 장치는 만들지 않고, NPC의 가치관은 그 NPC의 경험으로만 바뀐다.
- **미성년 캐릭터가 나오는 연애·성적 장면은 어떤 형태로도 만들지 않는다.** 고등학교 시절은 친구·무리·가족·알바·진로로 채우고, 연애는 성인 단계부터. 가출팸의 위험한 어른은 유혹으로만 나오고 막히거나 신고된다.
- **집단 고정관념 금지.** 국적·성별에 성격을 박지 않고, 다른 나라 이름은 가상.
- **종교는 중립.** 교리 판단 없음, 실제 단체 이름 없음, 사이비는 가상의 일반적 단체로만.
- **상표·로고는 가상.** 편의점·담배·소주 모두 가상 상호.

## 아트 방향

그림은 GPT가 그리고, 조립·움직임·엔진 연결은 코드가 한다. 기준은 위치브룩·스타듀밸리 수준의 도트.

**보는 방식**: 위에서 내려다본 3/4 시점, 원근 없음. 하늘은 안 보이는 게 맞고, 건물 뒤는 다른 지붕·나무·담으로 꽉 채운다.

**동네는 조립식**

- 바닥 타일(길 10종·땅 14종) + 건물 + 1층 가게 정면 + 간판 글씨(코드) + 거리 소품
- 글자 지도로 깔고, 길에서만 걷는다 (차도는 횡단보도로만)
- 가게가 망하고 바뀌면 1층 정면과 간판만 갈아 끼운다 — 도시 변화가 화면에 보인다
- 서울다움: 층마다 빽빽한 간판, 필로티 빌라, 엉킨 전선, 분리수거함, 마을버스, 교회 십자가, 재개발 가림막

**스타듀·위치브룩에서 따라 할 규칙**

- 바닥은 잔잔하게, 사람·건물·소품만 또렷하게
- 빈 땅을 남기지 않는다
- 키 큰 것(나무·가로등·전봇대)이 사람 앞뒤로 겹쳐 깊이를 만든다
- 그림자, 빛(저녁 창문 불빛), 바람에 흔들리는 나무는 코드가 얹는다

**캐릭터**

- 3등신, 한 칸 32×64 고운 도트 (게임 안에서 16×32 크기)
- 체형 8 (마름·날씬·보통·탄탄·근육·거구·통통·비만) × 남녀, 키 3단계는 코드로
- 기본 몸(회색 반팔·반바지, 머리·얼굴 없음) + 머리·얼굴·옷 부품
- 동작: 1단계 약 20 (걷기·뛰기·점프·알바 4종·들기·싸움 4종·앉기·공부·졸기·눕기), 2단계 약 30, 3단계 약 20
- 대화창 초상화는 눈·코·입·얼굴형·머리 부품 조합

**그림 받는 법**: 한 장에 한 동작, 기준 그림 첨부 → 도구(`tools/pixelize.py`)가 배경 제거·도트 크기·색 정리 → 게임에 바로 들어간다. 주문서: `src/ui/art/CATALOG.md`(동네), `CHARACTERS.md`·`PROMPTS-actions.md`(캐릭터).

## 기술 구조

엔진과 화면을 완전히 나눠서, 엔진은 화면 없이도 돌고 테스트된다.

| 층 | 기술 | 폴더 |
| --- | --- | --- |
| 엔진 | 순수 TypeScript, 시드 고정 난수(같은 시드 = 같은 세계), 테스트 112개 | `src/engine` |
| 게임 화면 | Phaser 4 (동네·편의점 장면) | `src/ui/game` |

| 빌드 | Vite, 서버 없음 | — |
| 그림 | GPT 이미지 + 정리 도구(Python) | `src/ui/art`, `tools` |

- 실행: `npm install` → `npm run dev` → http://localhost:5173
- 브랜치: `main` = 돌려 보면 확실히 되는 버전, 작업은 `feature/mvp` → 한 덩어리 끝나면 PR로 합침
- 엔진 규칙: `Math.random()` 금지, 숫자(밸런스)는 데이터로 빼고 `npm run sim:*`로 확인

## 현재 상태

엔진은 대부분 있고, 화면은 ‘동네 한 블록 + 편의점 알바 하루’까지 돌아간다. 가장 큰 병목은 그림이다.

| 부분 | 상태 |
| --- | --- |
| 엔진 (위 시스템 전부) | 돌아감, 글자 플레이(`npm run play`) 가능 |
| 아침 화면·정산 화면 | 돌아감 |
| 동네 | 타일 조립 한 블록: 빌라·상가(하루24·치킨집·학원·노래방·교회), 길에서만 걷기, 그림자, 문 앞 불빛·밀고 들어가기 |
| 편의점 근무 | GPT 매장 그림, 계산·진열·폐기·청소·양심 선택, 스타듀식 대화창, 근무 2분 남짓 |
| 주인공 그림 | GPT 걷기 시트 (2.5등신 임시) → 3등신으로 새로 받는 중 |
| 행인·손님 그림 | 아직 코드로 그린 임시 |
| 거리 소품·나무 | 없음 (깊이감이 부족한 이유) |
| 학교·집 장면 | 없음 (엔진에서만 돌아감) |

## 로드맵

먼저 **‘동네 하나 + 편의점 알바 하루’ 한 판을 진짜 재밌게** 완성하고, 그다음 넓힌다.

1. **캐릭터 그림**: 3등신 기준 몸 → 1단계 동작 19개(남자 보통 체형) → 게임에 넣기 → 나머지 체형·여자 NPC
2. **동네 그림**: 거리 소품·나무 → 건물 뒤 채울 것(지붕 줄·담·뒷골목) → 학교·아파트·교회·지하철역 → 공사 단계
3. **재미 검증**: 근무가 또 하고 싶어지나 → 속도·손님 빈도·양심 선택 다듬기
4. **하루 전체를 장면으로**: 학교(교실·복도·매점)·집(방·거실, 부모와 대화창)·PC방
5. **캐릭터 바이블**: 같은 반 친구·선생님·동네 사람 약 57명, 한 명씩 이름·얼굴·성격·사연
6. **마무리 효과**: 밤 창문 불빛, 나무 흔들림, 물결, 네온, 가게별 간판 글꼴

**대기 목록** (고등학교 다음): 고2·3 진급과 입시 · 진로 모듈(직업 틀 6개: 조직형·기술형·장사·선수·크리에이터·전문직) · 성인 연애·결혼(가치관·종교 궁합, 결혼 시기는 서로의 선택) · 집(월세·전세·매매·임대·청약·전세사기) · 군대(일요일 종교행사) · 재개발 이사 · 삶의 끝 평가(그 사람이 원했던 것 기준)
