# Claude 전달용 캐릭터 아트 패키지

## 포함 파일
- `BASE-BODY-REFERENCE.png`: 최신 캐릭터 체형/연령/방향 **디자인 참고 시안**. 실제 게임용 투명 스프라이트가 아님.
- `CHARACTER-SYSTEM.md`: 조립형 캐릭터 구조, 성장·체형·부상, 레이어 설계.
- `SPRITE-SPEC.md`: 규격 후보, 애니메이션, 파일 구조 및 QA 기준.

## Claude에게 전달할 요청
첨부 자료를 기준으로 현재 게임 프로젝트의 캐릭터 렌더링/애니메이션/에셋 로딩 구조를 먼저 분석해 줘. 기존 기능을 임의로 삭제하지 말고, 변경 대상 파일·데이터 모델·호환성 리스크·단계적 마이그레이션 계획을 제시해 줘. 64×128px은 미확정 후보이므로 실제 에셋 테스트 후 확정해 줘. 현재 PNG를 곧바로 실제 스프라이트 시트로 간주하거나 단순 크롭해서 완성 처리하지 마. 첫 검증 목표는 기본 체형 한 명의 4방향 표시, 이동 애니메이션, 의상 레이어 합성이다.
