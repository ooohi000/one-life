# 《한 번뿐인 인생》 캐릭터 커스터마이징 시스템 v1.0

## 상태
- 첨부 `BASE-BODY-REFERENCE.png`는 **디자인 참고 시안**이며, 실제 분리된 투명 PNG 스프라이트가 아니다.
- 기존 게임 코드와 충돌 여부는 아직 검토하지 않았다.

## 아트 기준
- 고품질 픽셀 아트, 선명한 윤곽, 계단식 명암, 약 3등신.
- 4방향: Down(정면), Left(좌측), Right(우측), Up(후면).
- 모든 Base Body는 머리카락, 눈, 코, 입, 눈썹 등 얼굴 파츠를 포함하지 않는다. 노년의 얼굴 주름도 Face 레이어에 둔다.
- Base Body는 비성적이고 해부학적으로 중립적인 피부색 마네킹형 신체로 디자인한다. 미성년자 캐릭터는 비성적인 기본 의상 표현을 적용한다.

## 조립형 캐릭터
- `BaseBody`: 연령, 체형, 피부색, 기본 신체 상태.
- `BodyEffects`: 상처, 흉터, 깁스, 부상 상태.
- `Face`: 눈, 코, 입, 표정, 노화에 따른 얼굴 변화.
- `Hair`: 헤어스타일, 색상, 흰머리, 탈모.
- `Clothing`: 상의, 하의, 외투, 기본 의상.
- `Shoes`: 양말, 신발.
- `Accessories`: 안경, 모자, 가방 등.
- 레이어 순서는 방향과 아이템에 따라 달라질 수 있으므로 렌더러에서 순서 규칙을 관리한다.
- 기본 신체는 완성형 스프라이트로 유지하고, 절단·의수·의족 등 특수 상태에서만 선택적 신체 파츠 교체를 지원하는 하이브리드 구조를 채택한다.
- 체형: 마름, 기본, 근육, 통통 등을 확장 가능한 데이터로 관리한다. 연령: 청소년, 성인, 중년, 노년 등. 최종 종류와 제작량은 미확정.

## 제작 순서
1. 기본 체형 4방향 마스터 1종을 실제 에셋으로 검증한다.
2. 의상·헤어·얼굴 레이어의 정확한 정렬을 검증한다.
3. Idle / Walk / Run을 우선 구현한다.
4. 앉기, 수면, 식사, 대화 등 일상 동작을 추가한다.
5. 직업, 운동, 성장·노화, 부상·재활 등의 동작을 확장한다.

## 주의
고해상도 참고 이미지를 단순 축소·크롭하여 완성 스프라이트라고 간주하지 않는다. 모든 에셋은 게임에서 실제로 합성·애니메이션 테스트를 통과해야 한다.
