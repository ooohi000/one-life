# life-sim (가칭)

서울 배경 도트 인생 시뮬레이션. 엔진은 화면과 분리된 순수 TypeScript.

## 실행

```bash
npm install
npm test          # 엔진 테스트
npm run typecheck # 타입 검사
npm run sim:day       # 화면 없이 고등학생의 하루 돌려보기
npm run sim:students  # 성실이 vs 밤샘이 2주 비교
npm run sim:half-year # 헬스맨·야식왕·축구부 6개월 (몸 + 공부)
npm run sim:body      # 폭식·대식·유지·소식·운동만·벌크업 6개월 체형 변화
npm run sim:npc       # NPC 10명의 고1 첫 주
npm run sim:npc-stats # NPC 200명 × 4주 분포 검사 (쏠림 탐지)
npm run sim:memory    # 엄마 3명이 같은 일을 몇 년 뒤 각자 다르게 말하는 대화
npm run sim:talk      # 내가 부모에게 말 걸기 — 부모 유형별 대화 + 1년 요약 (SHOW=warm,pushy)
npm run sim:family    # 집 1000곳 × 1년: 폭언·폭력·부부싸움·가출·가출팸이 현실 통계와 맞는지
npm run sim:justice   # 고등학생 1000명 × 3년: 특성·범죄·학폭위·소년사법·아동보호 (N=2000)
npm run sim:afterschool # 방과 후 싸움: 장소별로 누가 언제 알게 되나, 늦은 신고와 증거, 형편별 변호사
npm run sim:social    # 한 학년 600명 × 300일: 친구·무리·소문·또래 압력 (N=300)
npm run play          # ★ 글자로 플레이: 주인공으로 하루하루 고르기 (save로 저장, `npm run play -- load`로 불러오기)
npm run sim:seasons   # 1년의 날씨(월별 기온·비·미세먼지·옷차림·장마·첫눈) + 우리 동네 10년
npm run sim:carry     # 몸에 지닌 것: 우산·짐·폰·지갑, 비 맞기, 우산 같이 쓰기, 두고 오기
npm run sim:shift     # 편의점 근무 4번 (첫 근무·손에 익은 날·밤샘한 날·짠돌이 사장)
npm run sim:play      # 가상 플레이어가 주인공으로 10일 + 저장·불러오기가 같은 세계인지 확인
npm run sim:world     # ★ 하나의 세계: 고1 300명 × 1년, 월별 큰일·학년 통계·학생 이야기 (N=150 DAYS=120 SEED=8)
```

## 구조

```
src/
  engine/         순수 TS. React·Phaser를 모른다
    core/         EventBus, Random(시드 고정 난수)
    time/         달력, 시간대, 학사 일정, 지각 판정, GameClock
    character/    캐릭터 데이터, 생성(포인트·주사위·출신), 스탯 성장·감소
    body/         몸 상태(수면·졸음·스트레스·쓰러짐), 신체 구성(근육·지방·키·식욕), 증상
    npc/          성격·인생 목표·행동 데이터·두뇌(행동 점수)·하루 생활
  sim/            화면 없이 엔진을 돌리는 스크립트
tests/            Vitest
```

## 시간 엔진 요약

- 자유 시간엔 `tick()`으로 실제 시간에 맞춰 흐름 (속도: slow / normal / fast)
- 대화·메뉴 중엔 `pause(reason)` → 이유가 모두 `resume`돼야 재개
- 행동·이동·수면은 `advance()` / `advanceTo()` / `sleepUntil()`로 건너뜀
- 날짜·시간대가 바뀔 때마다 `clock.events`로 알림 → 몸 상태·NPC 시스템이 구독
- 창을 내렸다 돌아와도 한 tick에 최대 1초만 반영
- `toJSON()` / `GameClock.fromJSON()`으로 세이브

## 몸 상태 요약

- 시계 이벤트를 구독해서 깨어 있는 시간과 수면을 자동 계산
- 덜 자면 수면 부채, 더 자면 절반 속도로 상환 (최대 20시간)
- 졸음 = 깨어 있는 시간 몫 + 부채 몫. 부채 0이면 기상 후 21시간, 부채가 크면 13시간 만에 쓰러짐
- 숨겨진 수치가 선을 넘으면 증상(독백·외형 변화) 이벤트
- condition()이 스탯 상승량과 시험 컨디션에 곱해짐

## 신체 구성
- 몸무게 = 근육 + 지방 + 나머지. 잠들 때 하루 먹은 것·운동한 것으로 정산
- 근육은 근력 운동 + 단백질 + 잠 + 열량 여유가 있어야 붙고, 2주 넘게 쉬면 빠진다
- 힘은 근육량에서 계산 (따로 올리는 스탯 아님)
- 식욕: 적자가 이어지면 밥을 더 먹게 된다(몸의 항상성)
- 절전 모드: 오래 굶으면 소모량이 최대 15% 줄어든다(다이어트 정체기)
- 체형 8단계: 앙상함·마름·보통·탄탄함·근육질·덩치·통통·비만
- 기준(6개월): 폭식 → 비만, 대식 → 통통, 소식 → 앙상함, 운동 → 근육질
- 성장기 키: 잘 자고 잘 먹어야 남은 성장치를 다 채운다. 못 채운 몫은 사라진다

## 스탯이 녹스는 규칙
- 스탯마다 유예 기간·감소 속도가 다르다 (지구력은 빨리, 생활력은 거의 안 빠짐)
- 역대 최고치의 일정 비율 아래로는 안 떨어진다
- 예전 최고치 아래에서 다시 올릴 땐 1.8배 빠르다

## NPC
- 세 층: 성격 5요소(성실·외향·예민·친화·충동) / 태도(우월감·열등감·반항심) / 상태(번아웃·은둔 — 빠지고 나올 수 있음)
- 복합 목표 13종 × 동기 7종(좋아서·어울리고 싶어서·인정·두려움·갚으려고·가족·벗어나려고), 누가 정했나(나·부모·처지), 비밀 꿈
  - 좋아서 하는 목표는 자제력 없이도 끌리고, 하면 스트레스가 풀린다
  - 두려움으로 하는 목표는 늘 짓누르고, 안 하면 밤에 불안이 쌓인다
  - 번아웃이 오면 부모가 정한 목표가 꺾이고 숨겨둔 꿈이 커진다
- 외로움 바닥선: 친구가 없으면 폰·게임으로는 버틸 뿐, 친구랑 하는 행동은 부를 친구가 있어야 가능
- 행동 점수 = 욕구 해소 + 목표 × 자제력 + 성격의 끌림 − 피곤함 − 반복 피로 → 점수 비례 확률로 선택
- 학원·알바는 정해진 일정, 충동적이면 학원 땡땡이
- 플레이어와 같은 엔진: 지각하고, 살찌고, 녹슬고, 금요일엔 몰아서 잔다
- 장소 이동 시간, 통금(등교일 22시), 체력 한계 안에서만 행동
- 압박 바닥선: 부모 기대·학원·알바·형편이 만든 스트레스는 놀아서 다 풀 수 없다

## 기억과 대화
- `World`: 세계의 진실 (누가 어느 대학·군대·회사에 갔나, 언제부터). 아무도 직접 못 본다.
- `MemoryBank`: 사람마다 하나. 만난 사람(처음 만난 곳·맥락·인상), 그 사람에 대해 아는 것(직접 봄/들음/소문, 누구한테).
- 기억은 흐려진다. 진하게 만날수록 오래 간다(집 초대 ≫ 운동회에서 스침). 얘기를 듣거나 꺼내면 다시 진해진다.
- 이름이 기억 안 나면 단서로 부른다: "그때 우리 집 왔던 키 큰 애". 완전히 잊으면 언급 자체를 안 한다.
- 대화(`converse`)는 써둔 대사가 아니라 조립이다: 기억하는 사람 × 주제(`TOPICS`)의 "말하고 싶은 정도" → 상위 몇 개.
  - 주제: 근황 묻기(모르는 큰 소식) · 비교(우리 애보다 잘됨) · 은근한 자랑(우리 애가 나음) · 경계(첫인상 나쁜 애) · 추억
  - 말끝은 아는 경로대로: 소문 "~갔다며? 진짜야?" / 들음 "~갔대" / 봄 "~갔더라"
  - 같은 기억도 말하는 사람 성향(따뜻함·기대)에 따라 다른 말, 다른 스트레스가 된다.
  - 들은 대답은 기억에 남아 다음 대화에 쓰인다. 같은 비교는 되풀이하지 않는다. 아직 안 일어난 일은 모른다.
- 새 주제는 `TopicDef` 하나(salience + run)를 추가하면 모든 NPC 대화에 바로 쓰인다.

## 부모와 아이
- 부모는 유형 하나가 아니라 축의 조합(`family/parents.ts`): 사랑(속마음)·표현·기대·간섭·자기 우선·곁에 있음·화·술.
  - 사랑과 표현은 다르다: 무뚝뚝한 아빠는 "엄마한테 달라 해" 하고, 다음 날 책상 위에 봉투를 둔다.
  - 프리셋 9개: 다정함 / 무뚝뚝하지만 아낌 / 기대·비교 / 간섭 / 친구 같음 / 자기 우선 / 무관심·방임 / 화를 못 참음(술) / 사랑이 부족함.
- 아이 쪽은 애착(사랑·의지)과 두려움을 따로 센다. 맞고 자란 아이도 부모를 사랑할 수 있다.
  애착은 매일의 말보다 오래 쌓인 바탕으로 천천히 돌아간다.
- 플레이어가 말 걸기(`ParentTalk`): 그냥 말 걸기 · 친구 얘기 · 내 얘기 · 용돈 · 고민 · 챙겨 드리기 · 말대꾸.
  - 그냥 말 걸면: 미뤄 둔 챙김 → 못 들어 준 고민 → 자기 얘기 → 간섭 → 기억 속 소식 → 눈에 보이는 것(다크서클·살·PC방·늦은 귀가·알바·시험) → 잡담.
  - 같은 날 자꾸 말 걸면 귀찮아하고, 같은 잔소리가 반복되면 "몇 번을 말하니"가 붙는다. 문장 조각은 7일 동안 다시 안 쓴다.
  - 아이가 한 말은 부모 기억에 남는다(관심 없는 부모는 흘려듣는다). 처음 듣는 친구는 "네가 말하던 그 친구"로 기억한다.
- 폭언·폭력은 장면을 그리지 않는다. 소리·결과(멍)·아이에게 남는 것(두려움, 애착 하락)만 보여 준다.
  사랑이 있는 부모는 다음 날 사과한다(그리고 그 순환이 반복되기도 한다). 사건 뒤에는 도움 선택지가 뜬다:
  상담 선생님 / 112·아동보호전문기관 신고 / 친척 집 / 친구에게 털어놓기.

## 집과 가출
- 부모 유형 10개에 흔한 정도(가중치)가 있다. 같은 유형 안에서도 사람마다 ±0.1씩 다르다 (`sampleParent`).
  - 근거: 2023 아동종합실태조사 지난 1년 정서학대 36.5%·신체학대 14.5%, 공식 학대 판정 연 2.4만 건(가해자 84% 부모).
  - 그래서 평범한 부모도 가끔 소리를 지르고, 상습 폭력·심한 방임은 소수다.
- `Household`: 부모 한두 명 + 아이. 엄마·아빠가 서로 다른 유형일 수 있다.
  - 한 부모가 선을 넘으면 다른 부모가 막아서거나(아이의 두려움 감소, 부부 갈등 급증) 모른 척한다(그 부모에 대한 애착 하락).
  - 부부싸움은 아이에게 직접 안 해도 스트레스로 남고, 갈등이 쌓이면 별거한다.
  - `aversion()`: 집이 싫은 정도 → NPC는 저녁에 밖에서 버티고 통금을 어긴다 (`NpcLife.homeAversion`).
- `Runaway`: NPC는 확률로, 주인공은 선택으로 집을 나간다.
  - 근거: 일반 청소년 지난 1년 가출 2.5%, 위기청소년 22.6%(가족 갈등 69.5%, 가정폭력 28%). 가출팸은 SNS로 모인다.
  - 친구 집 → PC방·찜질방 → 거리 → 가출팸 / 쉼터. 대부분 며칠 안에 돌아온다. 돈이 떨어지면 버티기 어렵다.
  - 가출팸: 서열(막내는 심부름·상납), 생계형 범죄(결과로만), 경찰 단속 해체, 부모 동의서 없어서 못 하는 알바.
  - 출구: 스스로 귀가, 실종 신고로 경찰 발견, 1388 → 청소년쉼터 → 가족 상담 후 귀가 또는 중장기 쉼터·아동보호전문기관.
  - 미성년자가 얽힌 성적 내용은 어떤 형태로도 넣지 않는다. 위험한 어른은 "숙식 준다는 낯선 어른" 접근까지만 — 차단·신고로 이어진다.
- 주인공 집: 기본은 평범한 범위에서만 뽑는다 (`sampleParent(rng, { who: 'protagonist' })`).
  거친 가정(상습 폭력·방임)은 캐릭터 생성 때 "힘든 가정에서 시작하기"를 고를 때만 (`who: 'protagonistHard'`).
  NPC 세계에는 현실 비율대로 소수 존재한다 — 주인공은 친구를 통해 알게 된다.
- 콘텐츠 옵션 `ContentSettings.domesticViolence`: 끄면 폭력형 부모는 "엄하고 차가운 부모"가 되고, 술 마신 날에도 손찌검은 없다.

## 특성
- `traits/traits.ts`: 41개, 6분류(기질·싸움·사회·습관·재능·가족). 성격·태도·출신에서 2~4개가 붙고, 안 맞는 건 같이 안 붙는다.
  예: 일진 사냥꾼, 괴롭히는 버릇, 싸움꾼, 선빵필승, 평화주의자, 의리파, 오지랖, 눈치백단, 관종, 허세, 따라쟁이,
  스피드광, 손버릇, 한탕주의, 도박 기질, 독종, 모범생 기질, 반골, 말빨, 효자…
- 효과는 데이터: NPC 행동 점수, 스탯 성장 배율, 스트레스 배율, 싸움(걸기·실력·맷집), 정의감, 의리, 또래 압력,
  눈치(남의 멍을 알아챔), 오지랖(어른에게 말함), 범죄 끌림(폭력·속도·절도·쉬운 돈·도박·규칙), 말빨(선처).

## 싸움·학폭위·소년 사법
- 싸움(`justice/fight.ts`): 1:1·패싸움 같은 규칙. 남는 것 — 부상(멍/전치 2주/4주 이상), 목격자, CCTV(장소별), 촬영, 경찰.
- 학폭위(`justice/schoolViolence.ts`): 심각성·지속성·고의성·반성·화해 → 1~9호. 생기부 보존(1~3호 졸업 때 삭제 … 9호 영구), 대입 반영.
  정당방위는 쉽게 인정 안 된다: 먼저 맞았고 / 그 순간 그 정도였고 / 나중에 안 갚았고 / 증거가 있어야. 아니면 쌍방.
  일진 사냥꾼: 그 자리에서 막으면 인정되기도 하고, 방과 후 찾아가면 가해자가 된다.
- 범죄(`justice/crimes.ts`): 요즘 고등학생 기준 16종 — 폭행, 패싸움(SNS 약속·촬영), 상해, 삥, 괴롭힘, 무인점포 절도,
  오토바이 절도, 국경일 폭주(공동위험행위), 킥보드 무면허·2인(범칙금), 중고거래·게임 아이템 사기, 대리입금, 불법 도박,
  통장·폰 명의 대여, 보이스피싱 수거책("고액 알바"), 마약. 수법은 안 그리고 결과만.
- 소년 사법(`justice/juvenile.ts`): 경찰 → 훈방/선도조건부 기소유예/합의 → 소년부 송치(분류심사원 위탁) → 보호처분 1~10호,
  무거운 재범은 형사재판 → 집행유예 또는 소년교도소(부정기형, 상한 장기 10년·단기 5년). 촉법(10~13세)은 형사처벌 없음.
  보호처분은 전과가 아니고 수사경력만 남는다. 시설 처분은 그 기간 학교를 못 다닌다.

## 아동 보호
- `family/protection.ts`: 멍(7~10일, 대개 옷 속)·결석·움츠러듦 → 담임(신고의무자)·친구·주인공이 알아챔 → 아이가 털어놓거나 부인
  → 신고(아이 본인 신고 포함) → 아동보호전문기관·경찰 조사 → 증거 부족 / 원가정 보호 + 부모 교육 / 가해 부모 퇴거(임시조치) / 아이 분리.
  부모 교육은 사랑이 있는 부모일수록 먹힌다. 재학대도 있다. 근거: 판정 뒤 분리 9.4%, 재학대 15.9%(2024).

## 방과 후 싸움: 누가 알게 되나
- 장소(`justice/evidence.ts`) 13곳마다 CCTV에 찍힐 확률·보존 기간·지능형 감지·주차 차 블랙박스·지나가는 사람이 다르다.
  교실엔 CCTV가 없고, 번화가·지하철역은 거의 다 찍힌다. 공사장·빈 건물은 거의 안 찍힌다.
  근거: 공공 CCTV 176만 대(2023), 서울 약 20만 대(지능형 33%), 관제요원 1명당 477대 → 실시간보다 "나중에 돌려 보는" 증거.
- 발각(`justice/discovery.ts`): 현장 112·지능형 감지 / 맞은 애(보복이 무섭거나 자존심 때문에 안 말하기도) / 부모(멍·병원) / 목격자 / 영상 유포.
  아무도 말 안 하면 없던 일이 된다(대신 소문은 돈다).
- 증거: 가게 CCTV 1~2주, 공공 30일, 블랙박스 며칠이면 사라진다. 신고가 늦으면 입증이 어렵고, 부인하면 빠져나가기도 한다.
- 변호사(`justice/lawyer.ts`): 국선보조인·법률구조공단(무료) / 학폭·소년사건 변호사(약 500만 원) / 대형 로펌(수천만 원).
  선처·감경, 증거 다투기, 증거보전 신청, 합의 끌어내기, 맞신고, 행정소송(약 16% 일부 인용). 돈 있는 집이 더 산다 — 그게 현실.

## 관계
- `social/graph.ts`: 관계는 방향이 있다(나는 절친, 걔는 그냥 친구). 친함·믿음·존중(서열)·무서움·원한.
  친구는 정해 주지 않는다 — 같은 반 짝·앞뒤 자리, 쉬는 시간, 같은 학원 반·PC방 단골·운동장 팀에서 자주 마주치고 잘 맞으면 생긴다.
  잘 맞음: 성격이 비슷하고, 같은 곳을 다니고, 같은 특성. 끼리끼리(노는 애들끼리). 상극(괴롭히는 애 ↔ 일진 사냥꾼).
  안 만나면 멀어진다(절친은 천천히). `belonging()`이 NPC 하루의 외로움에 쓰인다(`NpcLife.socialBelonging`).
- `social/groups.ts`: 친구 관계가 뭉친 무리를 찾아 특성으로 이름을 붙인다 — 일진·폭주·의리파·운동부·겜돌이·모범생·인싸·예체능.
  대장은 존중을 제일 많이 받거나 센 애. 패싸움에는 무리와 의리 있는 친구가 모인다(`rallyForFight`).
- `social/rumors.ts`: 소문은 친한 사이를 타고, 말 많은 애가 더 퍼뜨리고, 옮겨질수록 부푼다.
  "한 대 때렸대" → "눕혀 버렸대" → "코뼈를 부러뜨렸대" → "원래 다른 학교 짱이었대". 들은 사람의 눈(존중·무서움)이 바뀐다.
  절친 험담은 안 퍼뜨린다.
- 또래 압력: 친구들의 반항심에 한 달마다 물들고, 친구들이 반항적이면 범죄가 약 2배.

## 입막음 (협박·회유)
- `justice/intimidation.ts`: 때린 애가 맞은 애·본 애를 찾아간다. 방식은 때린 애 특성으로 — 대놓고 협박 / 무리로 둘러싸기 /
  회유("매점 한 달 쏠게") / DM·단톡 협박 / 허세("아는 형들 많다"). 반응은 듣는 애 특성으로 — 겁쟁이·유리멘탈은 입을 닫고,
  깡다구·모범생·오지랖·일진 사냥꾼은 맞선다. 눈치 빠른 애는 수긍하는 척 녹음하고, DM은 캡처가 남는다.
- 협박 자체가 학교폭력이고 범죄(형법 제283조)다. 드러나면 학폭위 고의성이 오르고 최소 2호(접촉·협박·보복 금지)가 붙는다.
  입을 닫게 하면 안 들킬 확률은 오르지만, 증거가 남으면 더 크게 터진다.

## 하나의 세계 (`world/WorldSim.ts`)
지금까지의 시스템이 매일 한 루프로 돈다.
1. 미뤄진 일: 신고가 들어간 날 학폭위·경찰, 출석정지·소년원 복귀
2. 아침 집: 부모와 대화, 폭언·폭력, 부부싸움 → 스트레스·멍·가출
3. 각자의 하루(`NpcLife`): 등교·학원·PC방·알바·운동… 출석정지면 `결석(출석정지)`, 소년원·가출이면 `부재`
4. 만남: 같은 반 옆자리·쉬는 시간, 방과 후엔 오늘 타임라인에서 같은 장소(동네별)·겹치는 시간 → 관계 변화.
   자주 가는 곳 3개가 그 애의 단골이 된다. 내성적이면 먼저 다가가지 않는다.
5. 학교: 친구 없는 애가 괴롭힘 표적 → 실제 친구·일진 사냥꾼이 막거나, 입막음 → 참다 참다 신고(당한 횟수가 쌓일수록)
   → 원한이 쌓인 예전 피해자들이 "저도 당했어요" 증언 → 학폭위(6호 출석정지는 실제로 학교에서 빠짐, 7호는 반이 바뀜, 8호 전학은 학년에서 사라짐)
   → 싸움은 소문으로 퍼진다. 학대 징후는 담임과 "실제 친구"가 알아챈다.
6. 범죄: 친구들 반항심과 무리 성향이 또래 압력. 걸리면 소년 사법 → 시설이면 학교에서 빠짐
7. 소문 퍼짐, 한 달마다 무리 다시 찾기·친구에게 물들기

같은 시드면 같은 세계가 된다(저장·재현의 바탕). 300명 × 1년 약 1분.

## 주인공
- NPC의 하루는 이제 갈림길마다 멈추는 흐름(`NpcLife.dayFlow`)이다: 학교 갈까 / 학원·알바 갈까 / 지금 뭐 할까 / 잘까.
  NPC는 `liveDay()`가 AI 답을 넣고, 주인공은 플레이어가 답을 넣는다. **규칙은 똑같다.**
  주인공만 다른 점: 땡땡이칠 수 있고, 통금을 어길 수 있고, 새벽 2시까지 버틸 수 있다(대가는 몸에 남는다).
- 세계(`WorldSim`)에 주인공을 두면(`protagonist: 0`) 하루가 `beginDay()` → 플레이어 선택(`choose`, `answer`, `talkTo`, `talkToParent`) → `endDay()`.
  - 질문(`prompts`): 괴롭힘을 봤다(막아선다/선생님께 말한다/모른 척), 시비가 걸렸다(맞선다/말한다/참는다),
    입막음을 당했다(몰래 녹음/"말할 거야"/입 다문다). 답 안 하면 마지막 선택지(소극적인 쪽)로 흘러간다. 학교를 안 가면 질문은 사라진다.
  - `peopleHere()`: 지금 같은 장소(동네)·같은 시간에 있는 애들. `talkTo()`: 친한 정도·무서움·원한에 따라 반응이 다르고, 친하면 소문을 전해 준다.
- 저장(`save`): 시드 + 주인공의 선택 목록만. 열흘 플레이 약 3KB. 불러오기(`WorldSim.load`)는 같은 시드로 세계를 만들고 선택을 다시 넣는다
  → 완전히 같은 세계. (몇 년치가 쌓여 느려지면 중간 스냅숏을 추가한다.)

## 일: 직접 하는 노동 (`work/convenience.ts`)
- 일은 카드로 고르는 게 아니라 직접 한다. 근무 시계가 1분씩 가고, 손님이 줄을 서고(저녁 6~8시가 피크), 할 일이 생긴다:
  계산(바코드·거스름돈) · 진열 채우기 · 8시 폐기 · 청소. 일하는 동안에도 시간은 가고, 늦으면 손님이 화내고 나간다.
- 작업은 "미니게임 결과"(quality 0~1, 거스름돈 오차)를 받아 끝난다. 화면이 붙으면 플레이어의 손, 지금은 `autoHand`
  (근무 횟수로 손이 익고, 눈치·생활력, 몸 상태 — 밤샘한 날은 실수가 는다). "평소대로 하기"도 이걸로.
- 손님으로 이 세계 사람이 온다: 같은 반, 친구("야 이거 그냥 주면 안 되냐 ㅋㅋ"), 일진(신분증 없이 담배), 친구 엄마("엄마는 아시니?" → 우리 엄마 귀에 들어간다).
- 양심 선택: 미성년자 담배·술(단속반일 수도), 폐기 몰래 먹기(깐깐한 사장은 CCTV를 본다), 친구 공짜, 돈 더 낸 어르신, 도둑(일진이면 보복 원한), 취객, 마감 직전 무급 연장.
- 사장 유형: 착함 / 깐깐함 / 짠돌이(최저임금보다 적게, 계약서 안 씀, 주휴수당 떼먹기). 주급날 → 참는다 / 말한다 / 고용노동부 1350 신고(받아 내지만 잘린다).
- 청소년 근로 기준: 하루 7시간·주 35시간, 밤 10시 이후 불가 → 17:30~21:30 근무. 최저시급은 성인과 같다(10,320원).
- 세계 연결: `world.startShift()` → 화면(또는 글자)에서 직접 근무 → `world.finishShift()` → 돈·스트레스·관계·소문·엄마의 기억·주급날 질문.
  저장엔 근무 결과만 남는다. `npm run play`에서 알바 날 "간다"를 고르면 거스름돈을 직접 계산하는 근무가 시작된다.

## 사계절·날씨·도시 (`env/`)
- 날씨(`weather.ts`): 서울 평년 기온(최고·최저)을 바탕으로 날마다 뽑는다. 며칠씩 이어지는 따뜻한 주·추운 주, 장마(6월 말~7월 말),
  장마 뒤 무더위(폭염 33°↑), 태풍, 한파, 황사·미세먼지(봄·겨울), 벚꽃·단풍·첫눈. 어느 날을 먼저 불러도 같은 날씨(시드).
  옷차림 단계(반팔~롱패딩)는 도트 옷 스프라이트 번호가 된다.
- 세계 반영: 비·폭염·미세먼지면 NPC가 운동장 대신 PC방·노래방·카페로(`NpcLife.outdoor`), 폭염·한파엔 모두 조금씩 지친다,
  비 오는 날 편의점엔 손님이 늘고 우산이 팔린다.
- 도시(`city.ts`): 동네마다 부지와 가게. 공터·주차장에 공사 펜스 → 터파기 → 골조 → 입주(아파트 2~3년),
  가게는 생기고 사라진다(탕후루·인형뽑기 같은 유행 가게는 빨리), 재개발은 구역 지정 → 이주 → 철거 → 공사로 몇 년이 걸린다.
  우리는 직접 짓지 못한다 — 세상이 짓는 걸 보며 시간이 흐른 걸 느낀다.

## 몸에 지닌 것 (`carry/`)
- 아이템 창은 없다. 양손·주머니(옷 따라 2~4칸)·멘 가방(용량 L)·가방 속·입은 것. 들고 있는 건 도트 캐릭터에 그대로 보인다.
- 물건은 데이터 한 줄(`items.ts`): 들 수 있는 방법(주머니/한 손/두 손/가방/메기), 부피, 무게, 성질(전자기기·종이·깨짐·귀중품·음식·우산·눈에 띔).
- 행동은 규칙 한 줄(`VERBS`): 폰 하기(폰을 손에 들어야), 문 열기(손 하나), 계산(지갑·카드), 킥보드(두 손, 우산 금지), 싸우기(두 손)…
  → 한 손엔 우산, 한 손엔 떡볶이면 엄마 전화를 못 받는다. 택배 상자를 들면 현관문을 못 연다. 지갑 두고 나오면 계산을 못 한다.
- 비: 우산을 펴면 덜 젖고(태풍엔 소용없음), 안 챙겼으면 못 쓴다. 손에 든 폰은 비에 고장날 수 있고, 종이는 번진다.
  추운 날 젖으면 한기가 쌓여 감기에 걸린다. 비 그친 날엔 접은 우산을 두고 온다(덜렁댈수록). 우산 같이 쓰기 → 가까워진다.
- 무게: 많이 지면 걸음이 느려진다. 눈에 띄는 물건(기타·명품 가방·꽃다발)은 보는 사람 인상이 된다.
- 세계 연결: `npm run play`에서 흐리거나 비 오는 아침 "우산 챙길까?" → 그날 장소를 옮길 때마다 밖에 있던 시간만큼 젖고, 감기에 걸리기도 한다.
